Qualcomm 开发者博客介绍 Nexa AI 端侧 agent SDK 在 Snapdragon X PC + Hexagon NPU 上本地运行，全离线推理。

## 工作原理
Nexa AI NPU 优化 SDK 跑在 Snapdragon X Series，CPU/GPU/NPU 负载分配实现能效最优；端侧多模态推理、后台 agent、本地 LLM、文档理解全离线运行，数据不出设备。

## 实际效果
- 平台：Snapdragon X PC（Hexagon NPU）
- 能力：实时多模态推理 / 后台 agent / 本地 LLM
- 具体吞吐 / 能耗：未报告

## 创新贡献
展示 NPU 加速 agent 应用生态，Windows on Snapdragon 端侧 agent 落地路径，隐私敏感场景（受监管行业）本地化方案。
