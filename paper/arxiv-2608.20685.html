Temporal Validity on Real Software Histories: Eliminating Stale-Fact Errors in Code-Assistant Memory over GitHub Fixes

13 学校预印本 2026-08-21 · Neeraj Yadav / arXiv
方向:记忆应用:代码应用:RAG
这是什么MemStrata 显式记录代码事实被哪个新事实替代，避免代码助手把旧函数名、旧端点和新状态一起检索出来。
有什么结果130 个真实状态变化上准确率 0.91，RAG 为 0.57–0.59；RAG 强制作答时 36%–38% 选择旧值，MemStrata 接近 0。
怎么做到把软件状态表示为确定的主语—关系—宾语替代链，并在近似 RAG 延迟下检索当前值。
评分依据：摘要在真实 GitHub 修复历史上验证代码助手记忆的事实替代关系，直接减少旧 API、旧依赖被继续使用。
