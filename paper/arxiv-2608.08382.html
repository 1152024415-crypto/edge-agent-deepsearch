LLMVisor: A Real-Time Latency Attribution Model for Multi-Tenant LLM Serving

方向:调度服务方向:云端serving方向:评测基准硬件:GPU模型:Llama模型:Qwen
这是什么LLMVisor 为多租户大模型服务实时拆分每个请求的延迟占比，使同批请求的资源使用和性能责任可以被单独观察。
有什么结果在 A100、H100 及多种 Llama、Qwen 模型上，相比按 token 数估算，预填充尾部误差最多降低 3.3 倍，解码尾部误差最多降低 4.4 倍。
怎么做到它用屋顶线模型区分内存受限和计算受限阶段，再按 FLOPs 与内存流量构造可在微秒级运行的分段线性归因模型。
评分依据：这是数据中心多租户 GPU 服务技术，与手机或 PC 端侧距离较远；但实时、低开销的推理调度归因对资源受限运行时仍有相邻参考价值。
