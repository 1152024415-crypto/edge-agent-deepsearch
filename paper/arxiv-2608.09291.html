UnionSparse: An Index-Efficient Sparsity Framework for Low-Bit Sparse LLM Inference on Edge

17 学校预印本 开源 2026-08-10 · Tianhao Jiang; Hang Gu; Teng Wang; Qianyu Cheng; ZhenDong Zheng; Cheng Tang; Qiyue Su; Wenqi Lou / arXiv
方向:量化方向:剪枝稀疏方向:高效推理方向:编译部署硬件:GPU
这是什么针对边缘 GPU 上低比特稀疏大模型的索引元数据瓶颈，重新设计稀疏编码和矩阵乘内核，让压缩后的权重不再被索引流量拖慢。
有什么结果在 W4A4、30% 至 70% 稀疏度下，比 FlashLLM 快 2.30 倍、比 SpInfer 快 1.43 倍、比 CUTLASS 快 1.56 倍、比 cuBLAS Tensor Core 快 3.46 倍。
怎么做到用位图编码摊薄索引元数据，并在共享内存中并行解码低比特非零值，使稀疏遍历与张量片段组装对齐。
评分依据：直接针对边缘 GPU 的低比特稀疏推理，并给出完整内核对比和开源实现，是本批最强的端侧推理系统工作之一。
