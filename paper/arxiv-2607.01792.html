这是什么为 decoder-only LLM 选择性重复最有信息量的 prompt token，而非整段重复，降低 KV 成本。
有什么结果在八个基准（含 MMLU/GSM8K/RULER）三种模型族上保留全重复大部分增益，KV cache 仅用 59.4%、prefill FLOPs 仅用 79.0%。
怎么做到用 token 负对数似然作选择信号（难预测 token 更需后位重复），训轻量 gate 从早期层隐状态预测高 NLL token，在 prefill 中途早退出做选择。
