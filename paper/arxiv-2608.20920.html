ForeDreamer: A Self-Evolving Dual-Agent Memory Architecture for Future Event Prediction

12 学校预印本 开源 2026-08-21 · Linhao Zhong; Zongze Du; Linyu Wu; Yu Bo; Hourong Li; Chenchen Jing; Hao Chen; Yuling Xi / arXiv
方向:记忆方向:工具调用方向:规划推理
这是什么ForeDreamer 先把嘈杂网页证据整理成当前问题的事实记忆，再让跨任务经验持续改善搜索和预测。
有什么结果在 Prophet Arena 和 FutureX 上验证有效，摘要未报告统一提升数值。
怎么做到核心执行 Agent 负责搜索与预测，记忆子 Agent 用专用工具构造事实记忆，并以两条路径演化经验记忆。
评分依据：摘要将开放网页证据分为当前事实记忆和跨任务经验记忆，由搜索 Agent 与记忆 Agent 协同预测。
