Agent libOS: A Runtime Substrate for Capability-Controlled Self-Evolving LLM Agents

12 学校预印本 2026-08-18 · Yingqi Zhang / arXiv
方向:推理框架方向:工具调用方向:安全隐私方向:记忆
这是什么Agent libOS 为能长期运行、自建工具和派生子进程的 LLM Agent 提供一层带权限、信息流和审计控制的运行底座。
有什么结果33 项确定性运行任务全部通过任务与安全检查；12 次真实模型运行全部满足安全和严格效用要求，技能投影实验两组各有 13/15 次完全正确。
怎么做到把操作准入、敏感信息外发和因果审计分成三层，并用能力令牌、人类审批、预算和一次性释放限制 Agent 权限扩张。
评分依据：相关性 4/10，贡献度 8/10。Agent 运行时的权限与持久化机制可迁移到本地系统，但论文未给端侧设备部署；三平面与双重准入设计较完整。
