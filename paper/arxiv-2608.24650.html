Simthesizer: An Agent-Driven Simulation Framework for LLM Serving Systems

14 学校预印本 2026-08-25 · Wonung Kim; Hyunmin Choi; Minsu Kim; Jaehong Cho; Yeongwook Kim; Jongse Park / arXiv
方向:云端serving方向:调度服务方向:工具调用方向:评测基准
这是什么Borg 把 LLM serving 全流程做成可组合动态图，再让受约束的编码 Agent 自动扩展仿真功能。
有什么结果扩展后的仿真吞吐误差平均 2.51%，优于现有仿真器上的 6.03%；同负载最高快 284.96 倍和 23.19 倍。
怎么做到统一表达调度和执行流程，编码 Agent 只在该抽象上生成扩展，并用保真校验阻止错误修改。
评分依据：摘要用编码 Agent 把自然语言功能要求编译到可组合的 LLM serving 仿真图，并与真实 vLLM 系统校准。
