InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

14 学校预印本 2026-08-24 · Hanling Tian; Gengyu Zhang; Zeyang Sha; Jingying Wang; Yuhang Liu; Zhehao Huang; Kun Yang; Xiaolin Huang / arXiv
方向:记忆方向:安全隐私应用:安全
这是什么InjecMEM 只通过一次正常交互埋入可被后续检索的恶意记忆，让相关问题被导向攻击者预设输出。
有什么结果攻击在多种记忆系统和模型上保持稳定的主题检索与定向生成，在记忆漂移下仍有效且不影响非目标问题；摘要未给统一成功率。
怎么做到用高召回主题锚点保证恶意记录被找回，再优化短指令使其在不同上下文和位置中仍能控制输出。
评分依据：摘要提出只需一次交互、无需读写记忆库的 Agent 记忆注入攻击，并跨系统与模型评估。
