Stop restricting the agent. Start restricting its environment.

13 官方动态 2026-08-21 · Microsoft / Microsoft
Microsoft方向:安全隐私方向:工具调用方向:云端serving方向:规划推理
这是什么Microsoft 的结论是：提示词只能劝智能体守规矩，真正的安全边界必须放在它改不了的环境里。文章用 SRE Agent 的失效案例说明怎样隔离运行、代理凭据并按风险批准操作。
有什么结果给出四类生产失效及对应防线；未报告统一量化提升。
怎么做到用微虚机把执行环境隔离，把原始凭据留在代理层，按动作风险做确定性授权，并在输出离开沙箱前清洗敏感数据。
评分依据：没有端侧运行，但安全边界设计可以直接迁移到本地 Agent sandbox；真实失效案例提升了工程可信度。
