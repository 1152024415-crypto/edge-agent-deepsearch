PsychoAgent: An Affect-Sensitive Cognitive Architecture for Conflict-Aware Memory in LLM Agents

10 学校预印本 2026-08-07 · Mohammad Amanlou; Parham Abed Azad; Farbod Davoodi; Mostafa Masumi; Behnam Bahrak; Abdol-Hossein Vahabie / arXiv
方向:记忆方向:评测基准应用:RAG
这是什么PsychoAgent 把事实记忆和情感记忆分开管理，再由冲突感知控制器决定哪些经历进入当前提示。
有什么结果三个冲突场景中，完整架构检出关键冲突记忆的比例为 0.933，两个基线分别为 0.500 和 0.667；人工评价的校正后差异没有显著性。
怎么做到系统先按语义相关性过滤情感记忆，再用显著性重排，并持续更新未解决冲突和情感权重。
评分依据：这是 Agent 记忆架构，不含设备部署；情感维度和冲突控制有新意，但实验规模较小，人工评价优势未达到显著。
