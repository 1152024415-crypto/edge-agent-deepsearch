AstronOS: A Unified Execution Model and Runtime for Long-Horizon Agentic Systems

14 学校预印本 2026-08-17 · Zhenhang Nie; Gui Zheng; Xudong Sun; Tailong Zhu; Bin Zhang / arXiv
方向:记忆方向:推理框架方向:调度服务
这是什么AstronOS 让长流程任务不再依附某一次对话或 Agent 实例，而是用持久任务身份和版本化状态在多次模型调用之间可靠交接。
有什么结果主三阶段批次中通过 14/15 次，而重读原材料为 0/15、全历史回放为 2/15；通过一次任务的 token 成本更低但耗时更长。
怎么做到通过 Case、Task 和 Scenario Pack 管理权威状态，每一步只读取指定版本并在验证、记录后推进状态。
评分依据：相关性 6/10，贡献度 8/10。摘要提出跨多次调用维持任务持久身份与版本化权威状态的 Agent 运行时，并以 150 次软件更新任务对比多种交接方式。
