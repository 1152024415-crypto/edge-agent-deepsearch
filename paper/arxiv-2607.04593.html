TORINO: Token Reduction via Interpretable Concept Overlap in Vision-Language Models

11 学校预印本 2026-07-06 · Riccardo Renzulli; Gabriele Spadaro; Shruthi Gowda; Alaa Eddine Mazouz; Van-Tam Nguyen / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么用稀疏自编码器把 VLM 视觉 token 投到可解释潜空间，按概念重叠做自适应 token 缩减。
有什么结果在多个视觉语言基准上以最小性能损失减少视觉 token 数量，实现良好的效率-精度折衷。
怎么做到TORINO 用 SAE 把视觉 token 投到可解释潜空间，定义概念重叠为活跃 SAE 潜变量的一致度，按共享语义内容分组，组内做剪枝或合并；按输入复杂度动态调整缩减率。
评分依据：VLM token 缩减属端侧技术栈但非显式端侧（relevance 6）。SAE 概念重叠分组有创新（contribution 5）。vendors 空。
