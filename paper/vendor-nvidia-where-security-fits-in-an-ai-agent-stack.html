Where Security Fits in an AI Agent Stack

12 官方动态 2026-08-21 · NVIDIA / NVIDIA
NVIDIA方向:安全隐私方向:工具调用方向:规划推理方向:云端serving
这是什么NVIDIA 给出一张完整的 Agent 安全分层图：模型和 harness 决定智能体想做什么，安全运行时和基础设施决定它实际能做什么。安全控制应放到智能体无法绕过的更底层。
有什么结果未报告量化结果；文章给出从分发层到推理数据面的五层职责与控制原则。
怎么做到以最小权限、隔离、即时授权、凭据代理和审计组成硬边界，把可修改的智能体逻辑与不可绕过的环境策略分开。
评分依据：非端侧实现，但安全运行时分层能直接指导本机 Agent；主要贡献是清晰的系统框架而非实验。
