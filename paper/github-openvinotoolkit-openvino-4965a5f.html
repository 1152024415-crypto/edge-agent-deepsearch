14 开源大项目 开源 2026-08-25 · openvinotoolkit / GitHub
方向:推理框架方向:高效推理方向:KV cache方向:模型架构硬件:CPU
这是什么OpenVINO 为 CPU 增加了 SelectiveSSM 和分页 SelectiveSSM 的通用实现，让状态空间模型可以在 CPU 上用多精度和分页状态缓存执行。
有什么结果新增 2,874 行、修改 29 个文件并包含功能测试；未报告端到端性能数字。
怎么做到把头维度切成适配缓存的临时块，按 batch、序列、head 和 tile 并行，并用分页状态缓存调度长序列状态。
评分依据：OpenVINO 是端侧优先白名单项目，CPU 新算子和分页状态直接服务本地推理；但这是一项重要 feature commit 而非完整版本，且无性能数据。
