SkillOpt-Lite: Better and Faster Agent Self-evolution via One Line of Vibe

12 学校预印本 开源 2026-07-03 · Yifei Shen, Bo Li, Xinjie Zhang / arXiv
方向:工具调用方向:规划推理方向:高效推理
这是什么把 agent 技能优化形式化为零阶优化，砍掉冗余组件，三原则下用一行 vibe 让 agent 自我进化技能。
有什么结果LiveMath 上 GPT-5.5 +8.8 分、GPT-5.4-nano +25.4 分让 nano 超标准 GPT-5.4；集成 VSCode Copilot；SpreadsheetBench 上 nano 0.7758 超 GPT-5.5。
怎么做到零阶优化映射经典对应，三原则：文件系统轨迹探索、共识属性挖掘、独立验证门控；砍冗余得最小管线并推广到 harness 优化。
评分依据：agent 自进化技能，可迁移端侧小 agent 但非显式端侧（relevance 5）。零阶优化最小管线+三原则有方法学创新（contribution 7）。作者学校项目，开源。
