Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay

16 学校预印本 2026-08-07 · Nossa Iyamu / HuggingFace Daily
方向:端侧agent方向:记忆方向:高效推理方向:安全隐私
这是什么Activity Frames 用完全确定性的本地流水线把被动记录的屏幕活动编译成可审计、可重放的智能体记忆，减少重复调用大模型。
有什么结果在一名用户连续 51 个活跃日的 128,756 帧数据上，系统用 68 毫秒把单日记录压缩 86 倍；智能体问答准确率为 98.4%，确定性重放时模型令牌消耗为零。
怎么做到流水线把本地捕获流分割为带应用、站点、时间、输入量和原始证据指针的活动帧，并在规则匹配时直接重放已编译流程。
评分依据：虽然来源是屏幕活动，但核心贡献是无需模型的本地记忆编译、审计与重放，而非普通 GUI 点击智能体；单用户评估限制了结论强度。
