方向:推理框架方向:编译部署方向:量化方向:多模态硬件:手机硬件:MCU硬件:GPU硬件:Snapdragon
这是什么ExecuTorch 1.4 扩展 Cortex-M、Qualcomm QNN、Android、Vulkan 和 NXP 等端侧后端，并补充量化、大模型与视觉语言模型导出和性能分析能力。
有什么结果该版本扩大了微控制器、手机和多种硬件后端的模型覆盖；发布说明未给出统一的性能提升数字。
怎么做到通过统一导出流程、更多量化支持、动态形状处理和后端性能分析，把 PyTorch 模型部署到不同端侧运行时。
评分依据：ExecuTorch 是主流端侧推理框架，本次更新覆盖手机、MCU、QNN 和多模态模型，部署相关性很高。
