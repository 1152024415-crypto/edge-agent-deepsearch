Clustering and Token Denoising for Faster and More Robust VLMs

14 学校预印本 2026-08-19 · Baptiste Rossigneux; Inna Kucher; Vincent Lorrain; Emmanuel Casseau / arXiv
方向:多模态方向:剪枝稀疏方向:高效推理模型:Llama
这是什么ClustRS 不重新训练模型，就从每个语义簇挑代表视觉 token，并清理噪声，让 VLM 少算很多 token。
有什么结果极端噪声和压缩下可把视觉 token 减少 97% 至 16 个，性能最高超过对比方法 20%；轻噪声下不到三分之一 token 即匹配基线。
怎么做到先用注意力加权聚类保留语义代表，再对选中的 token 做一次残差收缩去噪。
评分依据：相关性 7/10，贡献度 7/10。摘要明确把视觉 token 负担与 edge deployment 联系起来，提出无需训练的 VLM token 剪枝与去噪。
