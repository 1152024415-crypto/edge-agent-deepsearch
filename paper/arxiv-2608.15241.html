LOCAL: Enabling Learning On-device Contiguously for Agent LLMs

20 学校预印本 2026-08-15 · Xinxin Liu; Jiaxin Li; Zibo Wang; Yun Ji; Zhangqi Zhu; Qing Hu; Zhibin Wang; Rong Gu / arXiv
方向:端侧agent方向:端侧训练方向:KV cache方向:调度服务方向:记忆硬件:GPU
这是什么LOCAL 让本地 LLM Agent 在服务用户的同时持续学习私人交互记录，不必把数据上传云端，也不用暂停前台推理。
有什么结果在 7B 模型与单张 24GB GPU 上，前台排队 P95 降低 3.1 倍，TTFT P95 降低 1.55 倍，发布后首次命中 prefill P99 降低 25.6%，跨 Agent TTFT P99 降低 21.9%。
怎么做到让协作调度器、版本感知 KV cache 管理器和多 Agent 运行时共享 adapter 版本、任务优先级与缓存状态，协调推理和后台训练。
评分依据：相关性 10/10，贡献度 10/10。摘要明确单张 24GB GPU 上的 on-device LLM Agent 在保持前台推理时持续从本地交互训练，运行时管理 adapter 版本、调度和 KV cache。
