CUDA Python 1.0: Stable APIs, One Foundation, Full Platform Access

11 官方动态 开源 2026-08-25 · NVIDIA / NVIDIA
NVIDIA方向:编译部署方向:推理框架方向:高效推理硬件:GPU
这是什么CUDA Python 1.0 把设备、内存、流、编译和数学库统一到 NVIDIA 维护的 Python 接口，并给生产依赖更稳定的版本承诺。
有什么结果未报告统一性能提升；Python 成为 CUDA 的正式一等接口，多套库可共享同一设备、流和内存对象。
怎么做到以 cuda.core 作为共同运行时对象层，上接算法、数学和内核编写工具，下接完整驱动与运行时绑定。
评分依据：通用 GPU 编程层可支撑推理部署，但不专为端侧；稳定 API 与共享资源模型有较强工程价值。
