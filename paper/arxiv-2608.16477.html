Pallas: A Proactive KV Cache Migration Framework for LLM Inference in AI-RAN

14 学校预印本 2026-08-17 · Tianhang Ding; Jianchun Liu; Hongli Xu / arXiv
方向:KV cache方向:端云协同方向:调度服务
这是什么Pallas 在手机用户切换基站之前提前准备 LLM 推理状态，避免用户已连到新基站而 KV cache 仍留在旧基站。
有什么结果相较目标侧恢复方案，平均服务中断时间缩短 2.28–89.68 倍；相较源侧转发，平均 token 间延迟降低 16.0%–50.0%。
怎么做到把序列分成稳定前缀和变化后缀，目标基站本地重算前缀，源站持续传输后缀 KV，并根据移动预测选择预取窗口。
评分依据：相关性 6/10，贡献度 8/10。摘要提出在蜂窝切换前将 LLM KV cache 主动迁往目标基站，vLLM 原型在多模型和多链路下显著缩短中断与 token 延迟。
