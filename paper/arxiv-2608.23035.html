MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

18 学校预印本 2026-08-24 · Yi Zhu; Xiongwei Wu; Qiyi Wang; Tingyu Qu; Jiajun Liu; Sihan Cao; Long Chen; Weigao Sun / arXiv
方向:工具调用方向:规划推理方向:记忆方向:评测基准硬件:手机
这是什么MobilePA-Bench 不测屏幕点击，而是在真实手机业务语义中测试 Agent 能否按权限和顺序调用工具、记忆与技能。
有什么结果覆盖 13 个功能域和 212 个移动工具；当前前沿模型在严格工具顺序、权限限制和运行时异常下性能明显下降。
怎么做到用维护实时应用数据库的沙箱执行工具，并以证据核验任务结果，同时测子 Agent 协作、记忆和复合技能。
评分依据：摘要明确评测移动规划 Agent 的工具调用、长时程规划、子 Agent 协作、记忆和技能，并使用可执行有状态沙箱。
