Evidence-Calibrated Runtime Reconstruction for Agent Skills Across Heterogeneous Coding Agents

10 学校预印本 2026-08-09 · Xueping Gao / arXiv
方向:工具调用方向:评测基准应用:代码
这是什么Skill Runtime Intelligence 用统一证据模型还原不同编码智能体中 Skill 从发现、加载到执行和验证的生命周期，避免把缺失信息误判为成功或失败。
有什么结果在三个编码智能体、六种仓库配置和七类正常或故障条件下完成 126 次执行；已知规则图对 126 次固定契约全部一致，而另一模型只完成 378 次调用中的 228 次。
怎么做到系统把原始事件、确定关系、推断诊断和受控结果分层保存，并用四级证据、适配器资格测试和可执行规则图重建运行边界。
评分依据：它解决的是智能体技能运行观测，不是端侧部署；不过被动、低侵入的生命周期重建对本地编码智能体的可靠性有相邻价值。
