Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory

15 学校预印本 2026-08-07 · Taeil Kim; Kangsan Kim; Sung Ju Hwang / arXiv
方向:蒸馏方向:记忆方向:工具调用方向:高效推理方向:评测基准
这是什么AMD 把大型教师智能体的成功经验整理成工作流、子任务和函数调用三层记忆，直接交给 40 亿到 80 亿参数的小型智能体使用。
有什么结果在 AppWorld、BFCL V3 和 ToolSandbox 上平均准确率分别提高 27.2、11.2 和 3.4 个百分点，其中 40 亿参数模型受益最大。
怎么做到任务开始时主动注入工作流和子任务记忆，工具调用出错时再按需检索函数约定和常见陷阱，无需重新训练学生模型。
评分依据：没有设备端实测，但它直接增强适合本地部署的小模型工具调用能力，而且训练免费、增益明确，对端侧 Agent 迁移价值高。
