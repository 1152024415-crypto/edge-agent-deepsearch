SkillSentry: Reliable Skill Execution for LLM Agents via Runtime Assurance

14 学校预印本 2026-08-10 · You Lu; Xinyu Huang; Bihuan Chen; Xin Peng / arXiv
方向:工具调用方向:安全隐私方向:评测基准应用:代码模型:GPT
这是什么在智能体执行技能时增加运行保障层，持续监控是否偏离技能步骤，并用历史成败轨迹更新指导规则。
有什么结果在 15 项技能、两类 Agent 和四种主干模型上，平均任务成功率提升 24.1%，重复运行的波动也更低。
怎么做到用专用语言表达技能运行约束，从技能文档和历史轨迹初始化规则，包裹 Agent 执行循环做实时监控、纠偏和迭代更新。
评分依据：运行时保障对端侧 Agent 的稳定工具执行有直接迁移价值，跨 Claude Code 和 Codex 的增益明显；但设备位置和本地执行没有明确说明。
