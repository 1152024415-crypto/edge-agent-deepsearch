CommitKV: Lifecycle-Aware KV Cache Compression via Commit Transitions for Multi-Turn Agents

15 学校预印本 2026-08-08 · Weizhong Huang; Jinchao Zhang; Xiawu Zheng / arXiv
方向:KV cache方向:记忆方向:高效推理方向:工具调用应用:长上下文推理
这是什么CommitKV 专门压缩多轮 ReAct 智能体的 KV 缓存，依据一次工具调用是否已经完成使命来判断哪些历史可以安全退休。
有什么结果多个智能体基准上同时降低内存、加快端到端推理，并比现有 KV 压缩方法取得更高准确率；摘要未给出统一数值。
怎么做到它比较工具调用提交前后删除某页 token 的影响，区分暂时沉睡的信息和已经完成作用的信息，再用联合测试控制批量淘汰风险。
评分依据：没有设备端实验，但它直接针对工具型智能体轨迹的缓存增长，能迁移到内存受限端侧 Agent；生命周期判断比单纯注意力淘汰更有针对性。
