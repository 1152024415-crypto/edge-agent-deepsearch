SPORK: Self-Speculative Forking to Accelerate Agentic LLM Inference

16 学校预印本 开源 2026-07-03 · Huajun Bai, Weiwei Lv, Huichuan Zheng, Youyou Lu, Jiwu Shu / arXiv
方向:投机解码方向:工具调用方向:高效推理模型:Qwen
这是什么LLM agent 的思考-行动-观察循环中 GPU 等工具返回常占 16-37% 墙钟时间；SPORK 让模型当自己的预测器，提前 fork 出工具名预测并行执行。
有什么结果Qwen3-32B 上工具名预测准确率 74.6-99.6%；GAIA P95 降 18%（131.9→108.1s）；覆盖 4B-32B dense 和 MoE 模型；准确率 1pp 内。
怎么做到生成起始 fork 探针预测工具名，prefix-cache fork 降成本，置信度门控过滤误测，部分 token 接受把拒测变投机解码草稿；拒绝则回退串行无正确性损失。
评分依据：agent 推理加速，工具调用并行隐藏等待，可迁移端侧 agent（relevance 8）。模型自预测+prefix-cache fork+部分 token 接受免训练创新（contribution 8）。作者清华，开源，学校项目。
