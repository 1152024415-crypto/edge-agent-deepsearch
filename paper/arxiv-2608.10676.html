Self-Correcting Long-Horizon Search Agents via Tree-Structured Memory

12 学校预印本 2026-08-11 · Aijun Yang; Qianxue Guo; Ziyi Huang; Yuxuan Chen; Shiyou Qian; Jian Cao / arXiv
方向:记忆方向:规划推理方向:工具调用应用:长上下文推理
这是什么为长时搜索智能体设计可自纠错的树状记忆，让新证据推翻旧结论时能定位错误来源并修复后续推理。
有什么结果在四个问答与搜索基准上，相比完整轨迹 ReAct 最高提升 25.6 个百分点；每步平均最大推理上下文更小。
怎么做到把搜索过程组织成证据树，每个节点保存有界摘要、原始证据和修订历史；发现矛盾后回溯到错误节点，替换证据、重写摘要、剪掉受影响分支并继续搜索。
评分依据：属于对端侧智能体很有迁移价值的有界记忆和纠错机制，贡献与实验结果较强；但论文没有设备端部署证据。
