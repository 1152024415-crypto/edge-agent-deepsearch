VisCache: Visual KV Cache Pruning for Efficient Vision Large Language Model Inference

16 学校预印本 开源 2026-08-25 · Lyuke Wang; Zhuo Li; Guangxu Zhu / arXiv
方向:KV cache方向:剪枝稀疏方向:多模态方向:高效推理应用:视频
这是什么VisCache 先筛掉视频冗余帧，再按层精细压缩视觉 KV cache，降低长上下文 VLM 推理成本。
有什么结果只保留 19%–28% KV cache 时最高加速 2.35 倍，并保持有竞争力的任务表现。
怎么做到轻量 VLM 选择关键帧，随后按抛物线层预算裁键、融合值，保留关键上下文。
评分依据：摘要提出无需训练的视觉 KV cache 两阶段裁剪，在只保留 19%–28% 缓存时报告速度与精度权衡。
