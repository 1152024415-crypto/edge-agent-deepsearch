Schema-Agnostic Graph Reasoning Agent for Hybrid Knowledge Graphs

11 学校预印本 2026-08-16 · Marius Dragic; Ruben Ifrah; Alexandre Rio / arXiv
方向:工具调用方向:规划推理应用:RAG
这是什么GRA 把知识图谱当作类似代码仓库的可探索环境，让 Agent 用列邻居、读节点、搜描述等通用工具自行发现结构。
有什么结果在 258 个工业分析问题上达到 88.4%，比全上下文 Agent 高 5.1 个百分点，同时读取不到三分之一的输入 token。
怎么做到只提供七个与领域无关的图工具，让模型按需导航文本概念和关系表节点，而不是一次塞入整个图。
评分依据：相关性 4/10，贡献度 7/10。摘要以 7 个通用工具让 Agent 在运行时探索陌生混合知识图谱，并在工业问答基准上超过全上下文 Agent。
