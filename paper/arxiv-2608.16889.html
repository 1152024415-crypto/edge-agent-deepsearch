Don't Drop the BATON: Long-Horizon Robot Manipulation via Agentic Subtask Exploration and Transition-aware Memory

16 学校预印本 2026-08-17 · Bingxin Xu; Yuzhang Shang; Emilio Ferrara / arXiv
方向:规划推理方向:记忆方向:工具调用应用:机器人
这是什么BATON 让机器人 Agent 分别探索和记住每个短子任务，再处理子任务之间的交接条件，减少长流程中的错误累积。
有什么结果在 RoboMemArena 上，任务成功率提高 11.6%，累计成功率提高 14.9%，探索成本从随阶段乘法增长改为近似加法增长。
怎么做到冻结 VLA 参数，由 LLM Agent 规划；用验证、交接和前瞻三类转移记忆决定何时调用动作模型以及如何恢复下一步可用状态。
评分依据：相关性 7/10，贡献度 9/10。摘要以 LLM Agent 规划、调用 VLA、写入语言记忆的机器人闭环为对象，BATON 将整任务探索拆成子任务并加入转移感知记忆。
