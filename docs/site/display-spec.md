# Site Display Spec

展示层只消费结构化论文数据，不负责搜索论文。最终形态以服务器页面为准，静态 GitHub Pages 只作为 fallback。

## 数据来源

服务器页面从 API 读取：

```http
GET /api/papers
```

写入洞察人和 wiki：

```http
POST /api/insights
```

主 agent 发布调研结果：

```http
POST /api/research-runs
```

完整字段见 `docs/site/api-contract.md`。

## 默认视图

使用高密度列表，一行一篇论文，不使用一篇占满一屏的大卡片。

列表列：

| 列 | 说明 |
|---|---|
| 分数 | 默认降序排序 |
| 日期 | 论文日期 |
| 论文标题 | 点击或展开详情 |
| 论文摘要 | 可截断展示 |
| 论文效果 | 必须来自原文；没有则显示 `未报告` |
| 工作原理 | 简述方法机制 |
| 论文连接 | 原文链接 |
| 洞察人 | 可编辑 |
| wiki连接 | 可编辑或跳转 |

## 排序

- 默认：`score` 降序。
- 必须支持：按分数、日期排序。
- 排序只改变展示顺序，不改服务器数据。

## 空状态

没有本周合格论文时，页面显示空状态。禁止展示旧样例或非论文内容来填充数量。

## 静态 Fallback

`app/build.py` 可以生成 `site/index.html`。该页面用于没有服务器时预览结构，仍必须遵守：

- 当前日期过去 7 天过滤。
- 只显示真实论文。
- 洞察人 / wiki 可降级写入 `localStorage`。
