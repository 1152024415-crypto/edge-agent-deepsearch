# Agent Research Publish Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the MVP pipeline where the main code agent validates a child research agent's paper results, publishes them to a server, and the server exposes the latest papers to the display page.

**Architecture:** Research agents write a structured run file under `research_runs/`. Local scripts validate and publish that run to a server. The server stores accepted papers in SQLite and serves `GET /api/papers`, `POST /api/research-runs`, and `POST /api/insights`.

**Tech Stack:** Python standard library, SQLite, static HTML generated by existing `scripts/build.py`, `unittest` for verification.
